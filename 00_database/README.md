# Rohdaten und Datenquelle

&nbsp;

Die vier Dateien wurden mit Beekeeper Studio aus der für das Projekt bereitgestellten PostgreSQL-Datenbank exportiert. Die Exportdateien wurden anschließend nicht verändert.

Es handelt sich um CSV-Dateien ohne Dateierweiterung, mit Kopfzeile, Komma als Trennzeichen und UTF-8-Kodierung.

| Datei | Quelltabelle |
| :---- | :---- |
| `unicorn customers` | `customers` |
| `unicorn orders` | `orders` |
| `unicorn order details` | `order_details` |
| `unicorn product` | `product` |
